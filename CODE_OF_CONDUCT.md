# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests,
discussions or any other project space.

Report unacceptable behaviour privately to the maintainers through a
[GitHub Security Advisory](https://github.com/AnshSingh30/AgentDesk/security/advisories/new) (it is the
private channel this repository has) or by contacting a maintainer directly. Reports are handled
confidentially. Maintainers may remove content, or temporarily or permanently ban contributors, for
behaviour they judge inappropriate, following the enforcement guidelines of the Covenant.
